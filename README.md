# Hardcore Forge

Build a Hardcore AI music generator app for instrumentals and MP3s. It features an interactive crate to browse, search, and scroll through types of Hardcore (Early Gabber, Frenchcore, Uptempo, Industrial Hardcore, Terrorcore, Hardcore Punk, Beatdown, Metalcore). Users can pick styles, customize prompts and tempo/distortion, and generate aggressive, raw instrumental audio tracks (no vocals, strictly heavy instrumentals, absolutely no cheesy chiptune). Include a dark industrial waveform audio player, generation history, and direct MP3 downloads.
